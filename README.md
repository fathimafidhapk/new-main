# VenueBook - Auditorium Booking Website

## About
VenueBook is a simple website that allows users
to view auditoriums and submit booking requests.

## Technologies
- HTML
- CSS
- JavaScript

## Features
- View available auditoriums
- Display auditorium capacity and price
- Select an auditorium
- Enter booking details
- Validate guest capacity
- Display a booking confirmation message
- Responsive design for mobile devices

## How to Run
1. Download or copy the project files.
2. Keep all four files in the same folder.
3. Open index.html in a web browser.
4. Select an auditorium.
5. Enter your booking details.
6. Click Submit Booking.

## Installation
No dependency installation is required.

No Node.js or npm is required.

## Limitations
This is a front-end demonstration project.
It does not store bookings in a database.
It does not send emails or confirm real reservations.

## Future Improvements
- Admin dashboard
- Database integration
- Real-time availability checking
- User login
- Online payments
